# Thư mục chứa hình ảnh báo cáo (report/images/)

Thư mục này chứa toàn bộ logo, biểu đồ kiến trúc và ảnh chụp màn hình giao diện thực tế của đề tài BTL.

## Danh sách hình ảnh tiêu chuẩn cần chuẩn bị:

1. **`logo_utc.png`**: Logo chính thức của Trường Đại học Giao thông Vận tải (ĐH GTVT). Đã có sẵn file mẫu, bạn có thể thay thế bằng file logo UTC sắc nét hơn.
2. **`architecture.png`**: Sơ đồ kiến trúc tổng thể Fullstack (Client -> Nginx -> Spring Boot -> MySQL / PayOS / S3).
3. **`bfd.png`**: Biểu đồ phân rã chức năng (Business Function Diagram).
4. **`usecase_overall.png`**: Biểu đồ Use Case tổng quát toàn hệ thống.
5. **`erd.png`**: Sơ đồ quan hệ thực thể Cơ sở dữ liệu (Entity Relationship Diagram - 13 thực thể).
6. **`seq_auth.png` & `seq_checkout.png`**: Các biểu đồ tuần tự (Sequence Diagrams).
7. **`activity_checkout.png` & `activity_stockcheck.png`**: Các biểu đồ hoạt động (Activity Diagrams).
8. **Ảnh chụp màn hình giao diện (Screenshots UI):**
   - `ui_login.png`: Màn hình đăng nhập hệ thống.
   - `ui_dashboard.png`: Màn hình trang chủ và thống kê KPI doanh số.
   - `ui_pos_explore.png`: Màn hình bán hàng nhanh tại quầy (POS Register).
   - `ui_pos_modal.png`: Popup tùy chọn biến thể (Variant) và nhóm tùy chọn (Modifiers).
   - `ui_payment_qr.png`: Popup thanh toán quét mã VietQR PayOS.
   - `ui_receipt.png`: Mẫu hóa đơn bán lẻ in nhiệt 80mm.
   - `ui_order_history.png`: Màn hình tra cứu lịch sử đơn hàng và hủy đơn bù trừ.
   - `ui_manage_items.png`: Màn hình quản lý danh mục sản phẩm và biến thể SKU.
   - `ui_stock_operation.png`: Modal nhập/xuất kho sổ cái và kiểm kê cân bằng kho.
   - `ui_manage_promotions.png`: Màn hình quản lý chương trình khuyến mãi (Coupon, Happy Hour, BOGO).
   - `ui_manage_customers.png`: Màn hình quản lý danh bạ khách hàng thân thiết CRM.
   - `ui_manage_users.png`: Màn hình quản lý nhân viên và phân quyền RBAC.
   - `ui_activity_logs.png`: Màn hình nhật ký kiểm toán hoạt động hệ thống.
