# POS_QUAN_LY_BAN_HANG

Phần mềm Quản lý Bán hàng (Point of Sale - POS) giúp quản lý và tối ưu hóa quy trình kinh doanh.

## 🚀 Công nghệ sử dụng

- **Frontend:** Vite, Node.js (nằm trong thư mục `Front-end/`)
- **Backend:** Java, Maven (nằm trong thư mục `billingsoftware/`)

## 🛠 Hướng dẫn cài đặt & chạy dự án

### 1. Chạy Backend (Java)
```bash
cd billingsoftware
./mvnw spring-boot:run
```

### 2. Chạy Frontend (Vite)
```bash
cd Front-end
npm install
npm run dev
```

*Yêu cầu: Máy tính cần cài đặt Node.js và Java (JDK) trước khi chạy.*
